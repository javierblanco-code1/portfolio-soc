01
SOC L1 · Análisis de logs · Detección

SOC L1 Log Analyzer

Problema: revisar miles de líneas de log de autenticación a mano es inviable en un turno.
Solución: parser en Python que procesa registros de Windows (Event ID 4624/4625) y Linux (auth.log), detecta ráfagas de intentos fallidos compatibles con fuerza bruta (MITRE ATT&CK T1110), accesos fuera de horario y cuentas con comportamiento anómalo.
Salida: un resumen priorizado por severidad, con usuario, IP de origen y ventana temporal, listo para abrir o descartar un ticket.

02Threat Intelligence

SOC L1 VT Enrichment

Problema: una alerta sin contexto no permite decidir si se cierra o se escala.
Solución: cliente en Python de la API de VirusTotal que enriquece hashes, direcciones IP y dominios, y devuelve reputación, cantidad de motores que detectan el indicador y un veredicto sugerido para el analista.

PythonVirusTotalIOC
03Network Security

SOC L1 Network Analysis

Problema: identificar en el tráfico qué es actividad normal y qué merece una investigación.
Solución: análisis de capturas de red para detectar escaneos de puertos, conexiones hacia destinos de baja reputación y anomalías en DNS y HTTP, con informe de hallazgos y criterio de escalamiento.

NetworkingSecuritySOC L1
04SIEM · Detection Engineering

SOC L1 Home Lab

Problema: entender una regla de detección en la teoría no es lo mismo que verla disparar sobre un ataque real.
Solución: laboratorio construido desde cero en VirtualBox: SIEM Wazuh, endpoint Windows instrumentado con Sysmon, y simulación de técnicas del framework MITRE ATT&CK con Atomic Red Team (Process Discovery T1057 documentado, con cadena de ejecución completa y reglas disparadas).

WazuhSysmonMITRE ATT&CKAtomic Red Team
